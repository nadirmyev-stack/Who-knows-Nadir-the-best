# Pulsuz internet linki üçün yerləşdirmə

Bu layihə Render-in Node.js web service formatına hazırdır.

1. ZIP-i açın və layihə qovluğunu GitHub-a yeni repository kimi yükləyin.
2. Render-də **New → Web Service** seçin.
3. GitHub repository-ni seçin.
4. Build command: `npm install`
5. Start command: `npm start`
6. Free plan seçin və Deploy edin.
7. Render sizə `https://....onrender.com` formasında link verəcək.
8. Həmin linki açanda iştirakçı səhifəsi gələcək.
9. `/host.html` əlavə edərək host panelini açın. Oradakı QR kodu ekranda göstərə bilərsiniz.

Qeyd: Pulsuz host xidmətləri müəyyən müddət fəaliyyətsizlikdən sonra servisi yuxuya keçirə bilər; ad günü zamanı host panelini tədbirdən əvvəl açıq saxlamaq yaxşıdır.
